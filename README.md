# Santu Sau - Developer Portfolio

A modern, responsive, and professional personal portfolio for a Full Stack Developer. Built strictly with HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Features

- **Modern UI/UX**: Premium dark theme with glassmorphism and subtle gradients.
- **Fully Responsive**: Flawless experience across desktop, tablet, and mobile devices.
- **Scroll Animations**: Smooth reveal animations using Intersection Observer.
- **Easy CV Download**: Direct, one-click PDF downloads from multiple prominent locations.
- **No Frameworks**: Pure HTML, CSS, and JS (No React, Bootstrap, Tailwind, etc.).
- **Jira Included**: Highlights essential Agile & Project Management tool experience.

## 🛠️ Setup & Usage

1. Clone or download the repository.
2. Ensure you have your actual CV PDF file placed at `assets/Santu-Sau-CV.pdf`.
3. Open `index.html` in any modern web browser to view the portfolio.
4. No build tools or servers are required for local viewing, though you can use tools like VS Code Live Server for hot reloading during development.

## 🎨 Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: CSS Grid, Flexbox, Custom Variables, Animations
- **Vanilla JavaScript (ES6+)**: DOM Manipulation, Event Listeners, Intersection Observer

## 📝 Note on Contact Form

The contact form includes front-end validation and a simulated sending state. To make it functional, you will need to connect it to a backend service (e.g., PHP mailer, Formspree, EmailJS).
